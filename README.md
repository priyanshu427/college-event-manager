**Campus Pulse** is a smart **College Event Management portal** that centralizes the planning, organization, and participation of campus events. The platform bridges the gap between students and event organizers by providing a seamless, digital solution for managing the entire event lifecycle. 

## Key Features

* 🎯 Interest-based event recommendations for students.
* 📅 Monthly event calendar for hackathons, fests, workshops, and other activities.
* 📧 Automated email notifications for upcoming events.
* 📝 QR code/link-based event registration with automatic database entry.
* 👥 Role-based access for Students and Organizers.
* 📜 Automatic certificate generation for verified attendees.
* ⚠️ Scheduling conflict detection to prevent overlapping events.
* ⭐ Feedback and rating system for post-event evaluation. 

## Objective

Campus Pulse aims to eliminate fragmented event management by providing a unified platform that simplifies event discovery, registration, communication, scheduling, and event management. It enhances student engagement while reducing manual work for organizers through automation and centralized management. 

## Target Users

* Students
* Event Organizers

**Campus Pulse** transforms campus event management into a streamlined, efficient, and user-friendly experience for everyone involved.
